生成されたアイコン

使用方法:

  1. 「アイコンを生成」ボタンをクリックして、各サイズのアイコンを生成します。
  2. 生成されたアイコンを右クリックして「名前を付けて画像を保存」を選択します。
  3. 各アイコンを適切なファイル名で保存します:
    • 192x192 → android-chrome-192x192.png
    • 512x512 → android-chrome-512x512.png
    • 192x192 (マスカブル) → android-chrome-maskable-192x192.png
    • 512x512 (マスカブル) → android-chrome-maskable-512x512.png
    • 180x180 → apple-touch-icon.png
    • 16x16 → favicon-16x16.png
    • 32x32 → favicon-32x32.png
  4. 保存したアイコンを public/img/icons/ ディレクトリに配置します。
